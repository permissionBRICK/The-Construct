The Construct · UI overhaul mockups

Four design directions for the Companion tray popup, the control panel and the host panel, plus a GUI installer and updater. Each design uses the same sample data, so you are comparing layout and style rather than content. Everything here is a static mockup, and no button does anything real.

Designs: Companion, control panel, host panel

01
Pulse
Status comes first, in a calm native Windows 11 look with light and dark themes. Each VM has one "next action" button. The control panel uses Settings-style navigation. The host panel is built around an attention feed.
Open →
02
Mission Control
Built around what the agents are doing, in a refined version of the dark Matrix look. Agents are the main element, with a notify inbox and "wake me when done". The host panel is organised by person.
Open →
03
Operator Line
Keyboard first, with a command palette and an event timeline, styled like a dense developer tool. The host panel is an ops console with filterable tables and bulk actions.
Open →
04
Floorplan
A spatial layout where the machine topology is the interface: forwards are drawn as wires and agents as cards plugged into the VM. The host panel is a RAM treemap with a what-if slider.

Installer and updater

05
Installer, setup wizard and updater
A compact updater with a progress bar and a drop-down live log. There is also a full first-run setup wizard covering install progress, blocking prompts, reboot, failure and success. The PowerShell one-liner stays the entry point.
