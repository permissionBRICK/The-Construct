Design notes

Two windows because two jobs. When the scripts need no answers (Update Construct, Reprovision, the Companion swap), a wizard is noise. When they need a dozen, a console prompt is hostile.

Glanceable

  • Percent from phase weights (Ubuntu download 20, unattended install 25, provision 30…), not step counts. ETA is a range ("about 8–12 min").
  • One plain sentence for "now" ("Ubuntu is installing itself inside the VM. Nothing to do.") plus one line of detail such as MB/s or Provision step 14/31.
  • The left rail becomes a phase checklist: done, active, pending, skipped ("ISO already present"), warn, failed, waiting.
  • Amber means "you're needed": the banner, striped bar, rail marker, taskbar overlay and Windows toast all agree.

One click deep

  • Details opens the live log: ANSI colours, All/Steps/Warnings/Errors filters, search, copy/save/open folder, "Jump to live" when you scroll up. Tokens are masked before they reach the buffer.
  • Review lists every answer with an Edit link. Warnings on the finish page expand to cause and fix.
  • Blocking cards replace hidden console waits: UAC, the certificate dialog, the VS Code tunnel device code (Copy + open github.com/login/device), and live-verified git tokens.

Deep

  • Pop the log out into its own window, or drag the split to resize it.
  • "Show as a PowerShell command" shows the exact Auto-Install.ps1 parameters the GUI passes (-FeatureSet, -VmMemoryGB, -Projects…).
  • Destructive existing-VM actions (Reinstall, Redownload, Remove) sit behind an unsaved-work scan, backup/restore questions and type-the-name confirmation.
  • BIOS virtualization and Windows Home guidance: open Setup · this PC, then Checks = BIOS off / Home.

New behaviour this assumes

  • A RunOnce entry reopens setup after the Hyper-V restart with the answers restored. Today the user has to re-run the script.
  • Every phase is idempotent, so "Retry from phase" is safe.
  • Scripts emit ##construct-progress{json}; until then the GUI parses ==> step lines.

Updater specifics

  • Closes itself 3 s after success ("Keep open" stops it). Stays open on failure with Retry and Copy log, and the log opens at the error line.
  • Blocked = paused amber stripes plus the process name holding the file (from Restart Manager). It never kills a process, which matches the script.
