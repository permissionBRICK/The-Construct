PulseDesign 1 · Construct UI overhaul

Status first, calm, native to Windows 11. Every surface opens with the same answer: which VMs are up, whether an agent is still working, and which links are live. Each state gets a single context-aware Next action (Open, Resume, Reprovision when Claude finishes). The rest lives in a Windows-Settings-style panel where every setting says when it takes effect. Destructive actions are one layer further down, behind an impact preview and a typed confirmation. Green means only "live and healthy"; amber and red are reserved for things that need you.
