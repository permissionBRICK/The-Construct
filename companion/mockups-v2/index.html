Construct Companion Independent concept set / v2

Three product models

One Companion.
Three ways to run it.

These prototypes reorganize the product, not just its pixels. Each direction covers instances, projects, settings, host administration, updates, usage, and the key vault. Click through the navigation, dialogs, approvals, and state changes.

01 / OPERATIONS

Atlas

A calm control room for several machines.

The selected VM is the primary object. A persistent scope bar keeps every action targeted, while operational detail moves into a right-hand inspector. The vault becomes a separate trust domain instead of another settings card.

  • Object-first navigation
  • Scoped settings
  • Progressive disclosure
Open Atlas
02 / GUIDED

Pathway

Start with the job, not the module.

The home screen asks what you want to accomplish. Multi-step work gets a visible plan and a review stage. Settings explain their effect before saving, and vault requests form an approval inbox with safe defaults.

  • Task-first home
  • Guided changes
  • Approval inbox
Open Pathway
03 / LIVE

Pulse

The Companion as an event-driven dock.

A unified timeline combines jobs, forwards, sync, updates, and vault activity. Selecting an event opens a detail pane without losing your place. Dense views, filters, and keyboard commands favor repeat desktop use.

  • Event-first home
  • Split inspector
  • Command-driven
